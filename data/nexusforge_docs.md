# NexusForge Knowledge Base

## What is NexusForge?

NexusForge 3.0 is a live, single-file, real-world agent swarm system that integrates multiple AI frameworks:

- **FractalAgentForge**: Core spawner for hierarchical agent creation
- **Auto-GPT**: Autonomous agent capabilities
- **BabyAGI**: Self-building and task management
- **SuperAGI**: Advanced agent orchestration
- **JARVIS**: Hugging Face inference integration
- **LangChain**: Tool integration and LLM abstraction
- **AutoGen**: Multi-agent debate and collaboration
- **CrewAI**: Team-based agent coordination
- **LangGraph**: Workflow state management
- **LlamaIndex**: Knowledge base and vector storage
- **Semantic Kernel**: Advanced reasoning

## Features

1. Real API calls - no mocks, no simulations
2. Real file writes to disk
3. Real subprocess execution
4. Real socket communication
5. Multi-threaded agent execution
6. Fractal agent spawning
7. Web search capabilities
8. Code generation
9. Knowledge base queries

## Architecture

The system uses a fractal architecture where agents can spawn child agents recursively. Each agent has:
- Unique ID
- Role and goal
- Parent-child relationships
- Memory storage
- Thread pool executor
